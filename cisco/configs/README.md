# Cisco configuration artifacts

| file | what it is |
| --- | --- |
| `SW01-baseline.cfg` | desired configuration rendered from `simulator/fixtures/environment.yaml` (port profiles + intent). This is the configuration-as-code source of truth used by the drift engine. |
| `SW01-running-config.txt` | `show running-config` as observed on the digital twin at the dataset baseline. It differs from the baseline in exactly the three deliberate drift items (`Gi1/0/22` description, `Gi1/0/35` storm control, `Gi1/0/41` enabled unused port). |

Both files are regenerated by `make seed`. Secrets are placeholders (`<REDACTED-…>`); the lab uses
RFC 1918 addressing only. Interface stanzas are produced by `cisco/templates/*` semantics as
implemented in `backend/sentinelswitch/simulator/cli_render.py::interface_config_lines`.

`diff cisco/configs/SW01-baseline.cfg cisco/configs/SW01-running-config.txt` shows the drift.

`../show-output/pre-quarantine/` and `../show-output/post-quarantine/` hold twenty `show` transcripts
each, captured from the twin before and after INC-2026-0042; compare
`show-interfaces-status.txt` or `show-interfaces-gi1-0-23-switchport.txt` between the two.
