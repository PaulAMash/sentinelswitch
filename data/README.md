# Synthetic dataset

Everything under `data/` is generated by `make seed` (`simulator/generators/run.py`) from the
canonical fixtures. It models one lab day, **2026-03-17 (UTC)**, on the SentinelSwitch digital twin.
All identities, addresses and events are fictional; external addresses use RFC 5737 documentation
ranges.

| path | contents |
| --- | --- |
| `zeek/` | `conn.log`, `dns.log`, `ssl.log`, `http.log`, `notice.log`, `weird.log` (Zeek JSON) |
| `suricata/eve.json` | EVE alerts and flow events |
| `radius/` | FreeRADIUS-style `radius.log` and `auth-events.jsonl` |
| `cisco/` | `SW01-syslog.log` (with PRI and sequence numbers) and `SW01-syslog.jsonl` |
| `seed/` | normalized seeds loaded into SQLite: inventory, users, alerts, detections, incidents, reviews, timelines, containment actions, traffic buckets, scenarios, the switch state at the baseline instant and after the flagship dry run |
| `generated/` | `events.jsonl` (normalized event stream), `flagship-events.jsonl`, `manifest.json` (counts and SHA-256 hashes); the SQLite database is created here and ignored by git |
| `incidents/` | evidence bundles; `INC-2026-0039`–`0041` are historical and committed, `INC-2026-0042` is produced by `make demo` |

The generator is deterministic: two runs produce byte-identical files (`manifest.json` proves it).
